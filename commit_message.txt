🐛 Fix: VPN builder IPv6 prefix crash

🐞 Проблема: Приложение падало с ошибкой `IllegalStateException: Cannot set address` на этапе установления VPN соединения (establish), если в конфигурации (AWG config) присутствовал IPv6 адрес с префиксом, отличным от `/128`.
🔍 Причина: Системный API Android VpnService.Builder требует, чтобы для добавления IPv6 адреса в интерфейс использовался префикс `/128` (host address). Передача любого другого префикса приводит к сбою.
✅ Решение: В YggVpnService.kt при парсинге адресов из конфигурации добавлена проверка — если адрес содержит двоеточие (IPv6), его префикс принудительно устанавливается в 128, независимо от того, что указано в конфиге. Для отладки в лог выводится соответствующее предупреждение.
🧪 Тестирование: Проект успешно собирается (assembleDebug, aar). Юнит-тесты и линтер (lint) проходят. Ручной тест конфигурации с IPv6 адресом, например `fd01::2/64`, подтверждает переопределение префикса на `/128` и успешное поднятие туннеля без креша.
